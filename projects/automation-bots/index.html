Telegram & Automation Bots

A set of Python bots for tracking changes, automating logins, aggregating local content, and applying to jobs.

Stack
Python, python-telegram-bot, aiogram, Playwright
Infra
Celery, Redis, PostgreSQL, Docker
Testing
pytest suites per bot

Overview

A cluster of automation projects, each solving a small real-world annoyance: being notified when remote data changes, grabbing a gym slot the instant it opens, pulling scattered local events into one feed, pushing newly published legal acts to people who care about a few sectors, and applying once to every matching software-engineer listing on rabota.md. Each one is written up on its own page below.
