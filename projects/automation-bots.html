Telegram & Automation Bots

A set of Python bots for tracking changes, automating logins, and aggregating local events.

Stack
Python, python-telegram-bot, aiogram, Playwright
Infra
Celery, Redis, PostgreSQL, Docker
Testing
pytest (41 tests / 8 modules)

Overview

A cluster of automation projects, each solving a small real-world annoyance — being notified when remote data changes, grabbing a gym slot the instant it opens, and pulling scattered local events into one feed.

What I built

  • Change-tracking bot — snapshot-diffs paginated third-party API data and alerts on deltas, with thread-safe SQLite persistence, retry/backoff with pagination, and 41 unit tests across 8 modules.
  • SSO booking bot — automates TU Delft gym-slot booking with a Playwright bot that drives a full OIDC/SAML NetID single-sign-on flow and retries on booking race conditions.
  • Event-aggregation microservice — a broker-based Telegram bot: aiogram with Celery + Redis workers and PostgreSQL (Alembic migrations), orchestrated via Docker Compose.

Highlights

  • Thread-safe persistence and resilient retry/backoff under flaky upstreams.
  • End-to-end browser automation through a real enterprise SSO flow.
  • Clean broker/worker separation for the aggregation service.
